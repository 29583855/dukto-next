## 已实现的主要能力

- 延续桌面配色与设备/最近/关于页面，提供触屏发送、接收目录、文本和应用文件入口。
- 复用桌面R6发现/文件/目录/文本传输核心，保留原版4644端口；与原版同机运行时需避免端口争用。
- 接入Next服务器配对、TLS、共享浏览、上传/下载、1/2/4/8/16通道、任务与可恢复引用管理。
- Android系统文件选择/导出、系统分享收件箱、组播锁、传输前台服务与通知停止；Android15内容安全边距。
- iOS文档选择/导出、安全作用域、有限后台收尾、文档打开和独立Share Extension收件箱。
- 有界导入、临时文件与持久引用、目录链接/替换防护、诊断和许可证材料采集。

这里的“实现”表示已有代码与列明的主机/合同证据，不表示所有手机系统行为已通过。iOS后台按有限收尾与恢复设计，不能承诺与桌面相同的常驻监听。

## 目录与使用说明

- `shared/`：从桌面提交a548b6ca复制的协议、传输、SQL与界面源码，仅修改移动副本。
- `app/`、`platform/`：移动宿主、触屏界面及Android/iOS集成。
- `scripts/`、`tests/`、`validation/`：固定依赖、原生构建、主机/合同/安装门禁。
- `docs/`、`evidence/`：开发计划、使用说明、实际检查收据与失败记录。
- `release/development/`：按源码/工具链分目录保存的开发产物，不是客户发行目录。
