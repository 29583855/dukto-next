# 文件浏览器窄屏布局修复

更新日期：2026-11-26。

Android真实导出验收run45693607360功能通过，但截图中“导出目录”按钮及路径/说明超出右边界。根因是四个操作按钮放在RowLayout中，最小总宽度反向撑大ColumnLayout内的其他项目；不会产生布局循环警告，因此原门禁没有发现。

修复将操作区域改为随可用宽度换行的Flow；路径、说明、分页和文件列表显式允许缩小到可用宽度。弹窗居中于窗口Overlay，随窗口高度保留16像素边距。

本机使用实际QML弹窗抽取探针：旧代码在360和320宽度存在越界，修复后360×640、320×640（请求1.5倍字体）和820×430三组全部零越界、零QML告警。首次尝试给Flow指定implicitHeight时因该属性只读加载失败，已删除该赋值并复验，保留此失败说明。该抽取探针结果不代表手机系统字体缩放验收。

真实220轮C++14主机门禁新增检查：应用文件弹窗内容宽度不得超过availableWidth；操作及导入区域所有可见按钮必须完全位于区域内，覆盖320/360竖屏及820横屏。完整主机回归和新APK设备截图仍待CI结果。
