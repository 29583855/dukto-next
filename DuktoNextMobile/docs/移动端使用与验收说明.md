# Dukto Next Mobile 使用与验收说明

更新日期：2026-11-25。此文面向正在开发的移动版本。当前已实现界面及平台适配代码，主机测试结果见《实施进度》。Android/iOS 的安装、真机互通与发行验收仍需逐项完成，不能直接将开发产物交给客户。

## 1. 系统范围与安装材料

当前构建目标为 Android 10及更新版本、arm64；iOS/iPadOS 15及更新版本、arm64。最低运行系统不等于商店允许提交的SDK版本。最终支持范围以实际安装记录为准。

Android测试APK与正式签名包分别标注。iOS未签名.app只证明编译，不是可安装IPA；真机安装需要有效团队、证书、描述文件和相应设备/分发授权。组播能力还需与实际签名一致。

下载材料应附提交号、SHA-256、最低系统、架构、签名情况、测试记录和许可证。缺少上述验证的文件不计入正式release。

## 2. 局域网互传

1. 手机和电脑连接允许设备互访的同一局域网，打开Dukto Next。手机先保持前台。
2. iOS首次出现局域网提示时选择允许；拒绝后到系统设置中修改再重新打开应用。Android按实际系统提示允许所需权限。
3. 在“设备”页等待发现。协议仍使用4644端口；同一台电脑同时启动原版Dukto和Next会有端口冲突，应只运行其中一个。
4. 点击目标设备，选择发送文字、剪贴板、文件或文件夹。找不到目标时可点击“IP连接”，填写接收端实际局域网IP与端口4644。
5. 发送端状态、接收端文件及内容哈希均核对后才算验收成功。R6协议没有远端完整性确认；发送端写出成功不能独立证明对方最终保存成功。

访客Wi-Fi、AP隔离、跨VLAN、VPN或防火墙可能阻断发现/连接。头像另用4645，Next服务器默认4646。发现可见与TCP传输可用是两项检查。

## 3. 选择文件、接收与导出

“发送文件/文件夹”调用系统文档选择器，只授权用户选中的范围。云端文件须先可读取。应用将源内容复制到私有暂存，再传输稳定快照；期间源文件改变、权限撤回、空间不足或超预算会显示错误。不会把Android content URI当成本机路径。

当前每次导入最多512项、32层；暂存总预算16GiB，保留64MiB空间，按64KiB分块复制。预算包含以前保留的暂存，已存在可恢复任务时不能随意删除。大量文件建议拆分目录；手机真实大文件验证仍待进行。

“应用文件”显示可供用户浏览的文档目录，每页最多512项，可上一页/下一页、进入目录、建立子目录。认证私钥和服务状态目录不在此列表中。设置中可更换应用文档范围内的接收目录。

点普通文件进入系统导出界面。进入某目录后点击“导出目录”，Android选择目标父文件夹，iOS选择系统提供的导出位置。Android目录导出拒绝同名根目录、符号链接、超过32层或65536项；不会覆盖已有目录。失败会尝试删除本次新建的目标根，提供器不允许清理时需要手动删除部分结果。系统提供器实际行为待真机验证。

“导入文件/目录”把系统选择内容移动到应用文件，遇同名项不覆盖。多项移动可能部分完成，界面会显示已完成数量；失败后检查已有结果再重试。

截图请先使用系统截图功能，再通过文件选择器选择截图。系统分享入口的实现和验收状态单列在计划中，不按桌面截图入口推断其可用。

## 4. 服务器上传与下载

“服务器·上传/下载”与LAN发送是不同入口。先在服务端创建身份、共享目录和客户端授权，颁发未过期的pairing-export开头JSON；不要把服务端内部状态JSON当成配对文件。

1. 在“连接文件”页导入pairing-export JSON并核对地址、端口、证书指纹与服务端共享名。配对文件按有效期使用，过期须重新颁发。
2. “已保存的服务器资料”是客户端连接别名，可自行命名；“共享名”必须与服务端配置一致，例如服务端配置为docs就填docs，不能用连接别名代替。
3. 点击“浏览”查询共享内相对路径。空路径表示共享根；远端路径不填写客户端绝对路径。
4. 下载时选择应用文档内已有保存目录，再选择下载内容和冲突策略。
5. 上传时选择有上传权限的共享及相对目标位置，再用系统选择文件或目录。核对任务状态和服务端落盘结果。
6. “任务”页查看具体任务、通道、暂停/取消/继续及分页条目；恢复只对支持恢复的Next任务和仍有效的本地暂存成立。

手机也可在“本机共享”页创建前台共享，限制到所选应用目录；按需要授予浏览、下载、上传权限。给其他设备使用的配对导出文件包含敏感授权，应通过可信渠道传递。

Windows Server 2012配对、上传与下载仍须用实际服务端回归；主机回环测试不等于该环境已通过。

## 5. 前后台与故障定位

当前前后台实现以保护状态为先：进入隐藏/挂起时取消活动操作并停止监听/发现，回到前台重新监听；原先由用户开启的Next服务会尝试恢复。Android可见期间持有Wi-Fi组播锁。前台服务/通知、iOS有限后台收尾以及锁屏持续传输仍有待完成和设备验证。

传输期间保持应用前台。切换网络、锁屏或系统终止后，重新进入应用检查任务状态；不要直接认定文件完整。Next可恢复任务需要原暂存和授权，R6没有断点续传。

找不到设备：核对网络、权限、IP、原版端口占用和防火墙。可发现但收不到：核对接收目录可写、空间、TCP4644可达，以及接收端状态。服务器认证失败：检查导入的是pairing-export、有效期、共享名、服务端指纹与客户端授权。

设置内“导出本地诊断”生成脱敏报告后调用系统导出。报告只供排障，提交前仍可自行查看；不要发送配对令牌、认证资料或私钥。
