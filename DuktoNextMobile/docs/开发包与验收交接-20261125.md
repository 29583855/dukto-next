## 3. 安装准备

请先查看《当前验收状态》选用最新修复包，旧android目录中APK已知模拟器启动失败。Android测试人员先在设备上核对系统≥Android10、arm64，记录手机型号、系统和包摘要。通过受控方式把调试APK传到手机并按设备提示安装，或在已配置ADB的测试电脑执行：

```sh
adb install -r DuktoNextMobile-android-arm64-debug.apk
```

最新90e8f8fe包已在GitHub Actions的Android15转译模拟器通过ADB安装、启动与首屏检查；本机未对真实手机执行该命令，尚无真实手机启动证据。APK只用于开发验收；正式签名、升级兼容、16KiB设备实跑和分发另列，不把调试签名当客户发行签名。

iOS需在macOS上使用本项目源码、Xcode与有效Apple开发团队重新构建和签名；同时为主应用`org.duktonext.mobile`与扩展`org.duktonext.mobile.share`配置匹配的描述文件和`group.org.duktonext.mobile` App Group，核对局域网广播/组播所需实际签名能力。签名配置见《构建与许可证说明》。未签名tar.gz是设备构建归档，不是IPA、模拟器程序或可双击运行的macOS软件。

本次设备包使用Xcode16.4/iPhoneOS18.5；这项原生编译证据不能代替计划所列的当前App Store工具链/提交规则验收。正式分发前仍需对应工具链构建与签名门禁。
