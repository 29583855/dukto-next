例如：

```powershell
$env:PATH="$PWD/.tools/msys64/ucrt64/bin;$env:PATH"
./build/windows-ucrt/dukto-cli.exe state gc preview --state-directory <应用状态父目录> --state-root service --json
./build/windows-ucrt/dukto-cli.exe state gc run --state-directory <应用状态父目录> --state-root service --json
```

`--state-root` 支持 `service`、`transfers`、`remote/service`、`remote/transfers`。GUI 原有 remote 位置按其实际目录使用。`more=true` 表示仍需下一批；退出 0 只表示本批无错误。`errorCount` 非零时保留候选并返回非零。自动尝试遇到活动共享使用者立即让出，后续正常业务仍执行原有严格核对。

进度文件不是删除授权。目录枚举顺序变化可能造成本轮重复或跳过，后续完整扫描周期再检查；每次删除都重新核对不可变证据。自动维护不初始化缺失目录，不把扫描库名称或 PID 消失当作所有权证据。
