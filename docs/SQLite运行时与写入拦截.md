# SQLite运行时与写入前策略

更新日期：2026-11-07。R119为总磁盘配额Q02的SQLite基础；全局预算、持久账本及自动GC继续实施。

Qt5官方Windows SQLite插件没有导出所需VFS和文件控制接口。不能拿另一份SQLite引擎的函数操作该插件的原生连接。项目改用固定SQLite 3.53.4源码，并编译Qt官方5.15.2完整SQLite驱动；宏只重命名内部类，注册名为DUKTO_SQLITE。系统QSQLITE插件仍可独立使用，数据库文件格式保持兼容。

生产连接经addSqliteDatabase创建；sqliteHandle只接受当前内部驱动、已打开连接及正确原生句柄类型。Qt的查询、绑定、事务、结果元数据及通知实现保留。SQLite作为C依赖编译，应用和驱动保持C++14。Qt私有头与安装的Qt补丁版本匹配，四原生平台分别构建验证。

每个连接注册独立随机名称的VFS，默认策略仅转发。策略可在打开、写入、截断、大小提示、共享内存映射及删除前返回SQLite错误码，拒绝时不调用对应原生操作；完成通知只报告已实际调用的结果。关闭及解除映射必须继续执行。文件名和事件临时共享，不保存文件正文或随传输增长的事件日志。策略不能抛异常；操作失败可能已经部分写入，不能仅按错误码归还全部预算。

SQLite文件锁、同步、短读和WAL锁仍由平台原生VFS处理。包装禁用块大小预分配请求，并让正文映射返回空指针，SQLite经读写方法访问正文。SQLite创建的回滚日志、WAL、临时库及排序溢写沿当前连接VFS。共享内存内部文件由原生VFS管理，映射策略给出请求范围；后续额度实现还需按各平台实际分配粒度及原生身份核对，不能将本接口直接作为物理磁盘硬限制。

路径使用UTF-8 URI转义，保留普通路径的中文、空格、#和%；POSIX另验证?。Windows文件名禁止?。显式URI保留mode等参数，强制当前连接VFS；空路径保留SQLite临时库语义。原SQLite插件和内部驱动的句柄不能互用。

对应源码归档和发布源码快照均包含third-party/sqlite-runtime内的原Qt源、SQLite ZIP、来源摘要和许可，其他third-party目录不进入归档。CMake在解压及编译前核验固定SHA256。摘要用于固定下载内容，不宣称上游签名验证。第三方原件保持原字节，不套用本项目格式化规则。

专项通过才记录：Unicode/Blob绑定与回滚、只读/旧插件互读、空路径/显式URI、写入/截断/大小提示拒绝后的摘要保持、真实SQL日志拒绝与同连接重试、WAL及共享内存拒绝、真实排序临时文件、32次注册释放与两连接隔离。完整CTest和原生CI按精确提交另验。

仍需完成：跨进程持久预算、所有状态根/原子替换/正文预算接入、真实身份和失败后重新核对、活动与历史/幂等分类、自动GC、资源压力及故障恢复。生产目前没有安装实际总配额策略，quotaEnforced=false。任意外部程序对目录直接写入不受应用策略保证。
