# 浏览快照到期回收

更新日期：2026-11-09。R145正在验收；本项是Q06/Q07的浏览缓存子项，整体交付与全局配额继续。

新建快照仍保留原有五分钟有效期、每主体两个及全根四个有效快照上限。发布正文及说明后，另写固定七字段的`snapshot-retention-<UUID>.json`，绑定状态根、正文和说明的原生身份、规范UTC到期时间及ready/deleting阶段。凭据不包含浏览正文、源路径或令牌。名称仅定位候选，不授予删除资格。

清理同时接入`state gc preview|run`、业务根打开前的机会式维护、R144长期TLS服务的空闲定时维护，以及持有`browse.lock`的新浏览创建路径。外部清理入口要求独占维护；创建路径持有全局浏览修改锁，并与外部维护通过共享/独占根占用互斥。两条路径共用同一身份和删除意图实现，不保留按前缀或修改时间直接删除的旧路径。

到期时间之前保留；恰好到期可清理。先核对所有仍存在的正文和说明，再持久化deleting意图，按固定父根与各对象原生身份逐项原生删除，最后复核并删除凭据。预览不改任何快照字节。取消、超时或进程直接退出留下意图，下次重验后继续；已经授权的删除意图在时钟回退时也可完成。任一同名对象或根换代、权限/格式损坏时保留现场，不据新名称或文件年龄重新认领。

旧快照无凭据时保持；发布凭据之前直接退出的孤立项保持；不能据此宣称所有历史浏览缓存已自动迁移或全部回收。未知项和已发布用户文件均不进入本回收。旧快照占用有效槽位而无法新建时，报告原数量/磁盘限制，不静默删除未知项；其显式迁移和处置仍待实施。

批量维护复用统一目录分页及时间上限，默认每批最多256个目录项，报告增加`browseSnapshotsVisited`与`browseSnapshotsCleaned`，计数均为十进制字符串；未改变`globalQuotaEnforced=false`。新浏览创建路径与之前一样逐项枚举，可观察取消，并不授予任意规模目录的总耗时保证。

验收原件见`docs/validation/2026-11-09/browse-retention-r145/`。初次编译的Qt类型错误、首次真实删除测试暴露的原生身份尾分隔符错误、一次文本替换引入的编译错误，以及正则未选中测试的空运行均保留。最终资格只按后续完整CTest和原生回执授予。
