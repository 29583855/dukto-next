# 有限重试与任务总时限

日期：2026-11-05；适用于新版 TLS 上传、下载、继续任务。GUI 与独立 CLI 共用 C++14 核心。

## 参数与默认行为

| 项目 | CLI | GUI | 约束 |
| --- | --- | --- | --- |
| 网络重试 | `--retries N` | 连接与文件页展开“传输重试和总时限” | 0–3 次，默认 0，初始尝试之外最多 3 次 |
| 总时限 | `--deadline-seconds N` | 总时限秒数 | 1–604800 秒，默认 86400 秒 |
| 单帧期限 | `--timeout N` | 当前固定 30 秒 | TLS 握手及每个协议帧的已有期限独立保留 |

这些参数仅适用于 upload/download/resume；其他 CLI 命令显式传入时返回配置错误 2。只接受规范十进制整数，重复选项、符号、空白、小数、前导零和越界值均拒绝。

默认手动恢复，不在软件重启后自动重跑历史任务。用户可对当前操作启用有限自动重连。旧 R6 没有新版幂等确认，不增加自动重试。

## 预算与错误分类

总时限采用单调时钟，从建立传输操作开始，覆盖恢复任务查询、本地强清单扫描、连接/认证、排队、正文、校验、提交确认及退避。恢复查询与正文阶段共享最多三次重试预算，成功进入下一阶段不重置预算。

只自动重试网络错误 3；退避依次为 250/500/1000ms。运行错误 1、参数/路径错误 2、身份/权限/排队拒绝 4、磁盘错误 5、完整性或源变化 6、取消 7 均原样结束。当前未把任何磁盘 I/O 错误判定为可安全自动重试。已知证书/主机名/TLS 握手校验失败归类为权限错误，不能因稍后的超时成为可重试网络错误。分类依据错误码与阶段，不匹配说明文字。

总时限到达使用错误码 3、阶段 `deadline`，保留检查点，不进入自动重试。用户取消优先返回 7。期限通过原子停止标志传递给扫描、控制和数据线程，等待/帧边界持续检查。不可中断的操作系统调用可能推迟退出，不能承诺严格到毫秒的强制终止。

每项当前操作只有一条取消/时限监视线程，固定约 10ms 检查；只观察原子标志和单调时钟，不跨线程访问 socket、SQLite 或 GUI。操作析构唤醒并 join，快速完成无需等待剩余时限。GUI 原有单槽快照及普通/控制操作上限保持有界。

## 幂等与完成判定

同一操作所有尝试使用同一请求 UUID、上传冻结强清单、授权共享/相对路径，以及下载保存目录和本地接收日志。上传失败重连不重新扫描或创建新内容身份。恢复从原任务取得方向/路径/请求；查询已 completed 时跳过 Resume，仍由原有上传/下载核心核对完成摘要，下载还复核本地文件。

重试事件 `transfer-retrying` 提供 retry、maxRetries、delayMs、code、stage、message；已知身份时附原 requestId/taskId，使 GUI 与 CLI 指向同一任务。GUI 显示“等待网络重试”，不创建新的列表项或积累所有事件。

网络断开可能早于远端暂停/取消错误帧到达。自动重连先查询原任务，遇到停止意图、paused/pausing/cancelled/cancelling 返回取消 7。新版服务在持有任务执行租约后也拒绝用重复创建恢复 paused，防止查询与重新创建之间的竞争清除暂停；必须显式 `resume --task UUID` 或点击继续。重复创建被拒绝时保持 paused 及检查点，不执行非法的二次暂停转换。旧服务只能得到客户端查询保护，服务端竞争保护需要新版服务；无意更改原任务状态的旧请求可能需要改用其已有的显式 Resume。

只有已经通过任务持久完成确认与清单核对的结果才视为成功。该确认之后关闭会话时发生网络错误或取消，不撤销完成结果。确认之前断网仍须同请求重试并重新核验；单个文件完成或全部正文发出都不能冒充批次完成。

## 验证与范围

核心测试覆盖严格参数、多个阶段共享次数、指数退避、永久错误、无事件循环时的期限、真实强清单扫描检查点、退避取消、线程回收及任务身份。真实 TLS 专项见 `tests/transfer_retry_integration.py`，包括 1/4/16 通道双向中途断线复用、同名保护/无副本、连接拒绝次数封顶、证书/权限不重试、排队和正文总时限。最终确认丢失另由 `tests/final_ack_integration.py --auto-retries 3` 验证；默认参数继续覆盖手动恢复。

Windows 双工具链、原生生产服务器面板及发布包的实际结果按主计划增量逐条登记。工作流配置不等于三平台运行通过；Linux 当前固定排队快照不含本契约，验证驱动退出归档前不得替换。macOS、物理 LAN、全部资源/磁盘预算和完整产品交付仍按主计划独立验收。
