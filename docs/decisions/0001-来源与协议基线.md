## R6 线上格式

来源：两个镜像的 `duktoprotocol.cpp`，待保存原版实际双向样本后关闭 T04。

- UDP/TCP 默认端口均为 4644；头像 HTTP 为 4645。
- UDP 首字节：`01` 广播 Hello、`02` 单播 Hello、`03` Goodbye、`04/05` 带自定义端口的 Hello；后两者附 16 位端口。后续内容为 UTF-8 的 `用户名 at 主机名 (平台)`。
- TCP 开头为两个有符号 64 位小端整数：条目数、文件数据总字节数。
- 每个条目：UTF-8 相对路径 + `00` + 有符号 64 位小端长度；长度 `-1` 表示目录，非负数后紧跟对应长度的内容。空文件长度为 0。
- 文本使用路径哨兵 `___DUKTO___TEXT___`，单条目，长度为 UTF-8 字节数。截图按普通 JPEG 文件发送。
- 原版没有端到端摘要、远端落盘完成确认、服务器目录浏览、客户端拉取、暂停/恢复或并行块协议。兼容路径不得发送新版帧，也不把本机 socket 排空当作远端已校验。

新实现为包头分片、路径/名称长度、非法整数、条目数量、总字节数、提前断线、磁盘短写及资源释放定义错误处理。目录清单使用受限磁盘数据库；不能沿用上游全部放入 QStringList 的方式。

匹配的公开 R6 源码没有主动截图函数/发送入口；Qt5 历史移植虽有截图代码，其发送页按钮已注释，与本机原版发送页观察一致。新版截图按新增扩展保留并继续做三平台验收；普通 JPEG 文件与原版双向互传已核对，不能将该记录写成原版主动截图操作。证据见 `original-screenshot-baseline.json`。
