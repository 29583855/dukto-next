# 文件冲突与逐项完成契约

日期：2026-11-05。状态：默认 rename、新版 fail 与显式 overwrite 已接入核心/GUI/CLI，Windows 双工具链实际验证通过；overwrite 新原生/实际包资格、skip及完整 R03 验收仍未完成。四策略表继续作为完整目标。

## 用户选择与适用范围

新增统一参数 `--on-conflict rename|skip|overwrite|fail`，默认 `rename`。GUI 在发起上传/下载前按整个批次选择，初始显示“保留双方（自动重命名）”；覆盖选择必须清楚显示会替换同名普通文件。恢复已存在任务时展示原策略，不能修改它或静默采用当前界面的值。

新版上传的策略由服务端执行，下载由本地接收核心执行。R6 协议没有协商冲突策略的字段，兼容发送不能控制对方接收规则；本地 R6 接收入口的策略另行接入同一文件提交适配层。未实现入口不得接受并忽略参数。两种协议的界面和帮助必须准确说明实际执行端。

## 四种策略

| 策略 | 同名普通文件 | 同名目录 | 类型不同或不安全目标 |
| --- | --- | --- | --- |
| rename | 保留原文件，独占分配带后缀的新名称 | 分配独立目录，后代沿持久映射写入，不合并 | 不跟随链接；安全可分配新名称时保留双方，否则明确失败 |
| skip | 保留原文件并记录跳过；不下载/发送该项正文 | 跳过该冲突目录及其整个源子树 | 链接、重解析点、特殊文件及不可访问目标明确失败，不伪装为普通跳过 |
| overwrite | 新内容完整校验并同步后，在同目录原子替换目标 | 复用已安全固定的普通目录；逐文件替换，保留目标中不在源清单里的项目 | 文件与目录互不替换；链接/特殊文件拒绝；不递归删除已有目录 |
| fail | 首次确认冲突即报告冲突错误 | 同样失败，不合并 | 明确失败 |

源清单内部的大小写折叠/NFC 重复仍在扫描阶段拒绝，不使用覆盖策略掩盖重复。既有目标的判断需要同时覆盖准备与最终提交期间的并发出现，不能仅做一次 `exists()` 后直接截断目标。默认 rename 的已有任务及旧日志保持原语义。

## 原文件保护与任务边界

所有新正文仍写同目录独占临时文件，完成全文件 SHA-256、文件同步、原生原子发布和目录同步后才能确认该项成功。覆盖模式禁止直接打开原文件并截断，禁止用复制后删除代替原子替换；文件系统不支持所需原子操作时明确失败。

任务取消、权限撤销、磁盘满、摘要失败和进程退出发生在发布之前时，原文件保持不变。若退出发生在原子发布之后、日志确认之前，恢复按提交意图中的临时文件原生身份和最终内容确认同一个结果，不能再次覆盖其他后来出现的文件或分配副本。发布后原结果又被用户改动时报告完整性错误。

批次采用逐项提交，允许先前项目已完成、后续项目失败；界面与结果必须显示部分完成。`fail` 不承诺整个目录树的原子事务。跨任务的目标预约必须参与同一目录的冲突裁决；同一用户在程序外任意改写目标树的竞争边界须记录，不能只凭任务锁宣称文件系统具有比较并交换能力。

## 持久化、幂等与恢复

1. 创建请求摘要绑定所选策略。相同请求 ID 换策略返回完整性错误；并发数仍可在显式恢复时调整。
2. 默认 rename 在内部保持旧 `keep-both` 规范值，兼容旧请求摘要。新非默认策略采用版本化字段；未知值拒绝，不回退到 rename。
3. 接收日志绑定策略、任务、冻结强清单和目标根原生身份；既有日志按旧格式明确解码。架构迁移必须事务化，保留旧版本恢复测试。
4. 每项落盘 `copied`、`skipped` 或失败证据，目录子树的跳过通过磁盘清单/索引解析，不能在内存中保存全部后代列表。
5. 跳过决定在向对端确认前持久保存，恢复不重新根据当前是否同名决定复制或跳过。旧临时文件只能按日志绑定身份处理，不按名称猜测归属。
6. 完成确认丢失后，查询及重复请求返回原策略、原逐项结果和实际最终名称；不重做覆盖，不生成多余后缀文件。

## 协议与完成语义

扩展能力必须显式协商。旧对端仅支持默认保留双方，非默认请求在发送正文前明确拒绝；不能把新选项发给旧端后假定其会执行。新增字段采用严格枚举和有界长度，仍沿用任务主体授权及原清单内容身份验证。

结果区分“复制并校验”“跳过”“失败”“未执行”。`skippedBytes` 不计为网络发送量、持久已接收量或 SHA 校验通过量，不能把跳过项目伪造成已复制。任务已完成表示各项按所选策略处理完毕；含跳过时 GUI/CLI 明示数量，目录明细可分页查询。最终确认与查询需交叉核对各项数量、处置摘要和总量，沿用明确的版本化结构，不能放松当前强清单确认校验来接纳新结果。

非交互 CLI 不弹框；合法 `skip` 完成退出 0 且明示跳过计数，`fail` 的目标冲突返回 4 / `conflict`，非法参数返回 2。冲突不是可自动重试的网络错误。GUI 的批次选择、等待/暂停/继续、部分完成和错误提示共用同一结果模型。
