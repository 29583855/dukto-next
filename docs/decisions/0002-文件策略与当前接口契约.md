# 文件策略与当前接口契约

日期：2026-11-04；适用当前 R6 兼容核心。新版服务、分块和恢复接口须另有版本化协议决策，不将本记录作为它们已实现的证据。

## 文件与失败行为

| 边界 | 当前已执行的规则 | 后续必须补齐的范围 |
| --- | --- | --- |
| 普通文件/目录 | 传普通文件、空文件、空目录及目录树；流式清单写磁盘 SQLite | 元数据保留和完整批次失败报告 |
| 名称 | UTF-8 相对路径；拒绝绝对路径、穿越、NUL、Windows 保留名/非法字符、尾点/尾空格 | 文件系统 Unicode/大小写差异的三平台原生结果 |
| 路径重复 | 批次内 NFC + casefold 冲突明确失败；同名顶层扫描分配不同别名 | 新服务预约、覆盖/跳过/失败策略及并发竞争 |
| 同名落盘 | 默认自动后缀，现有原文件保持不变；目录另分配独立根 | 当前 CLI 不提供尚未实现的 `--on-conflict`；完整四种策略仍为 R03 范围 |
| 临时与提交 | 同目录临时文件，成功写入并关闭句柄后原生不覆盖命名，禁止复制回退；Windows 同名并发与失败清理通过 | Windows 目录链句柄/不允许删除共享已验证；Linux openat/mkdirat/renameat2 固定句柄与替换清理已验证，macOS 原生待验；不支持原生提交的文件系统明确失败 |
| 链接/特殊文件 | 清单拒绝链接、设备/管道等特殊文件；当前根内解析拒绝已存在链接 | Windows junction 根拒绝及真实接收父目录改名拒绝已验证；Linux 根/子目录替换及符号链接根拒绝已验证；macOS 原生仍待验证 |
| 源变化 | 扫描前后 size/mtime，以及读不到声明字节时失败；实际传输中改变大小已返回完整性错误 | 新版恢复不能仅依赖 size/mtime，须绑定强内容身份并重核已有块 |
| 部分失败 | 已提交文件保留；整批非成功；接收明细保留最终路径、字节及摘要 | 新版逐项失败/未执行项报告、幂等最终确认 |
| 持久性 | 当前成功指完整接收并提交，本地算 SHA-256；不承诺断电持久 | 新协议文件/目录同步、检查点顺序和崩溃注入 |
| 进程退出 | 接收任务持跨进程锁，关闭年龄失效判断；存活所有者不被抢占，失去所有权的 `receiving` 记录标为 `interrupted`、结果未知 | 真实强制结束进程已验；未入库的已提交文件及遗留临时文件须核对，自动清理与新版恢复仍待实现 |

POSIX 目录句柄固定已打开的 inode，不能像 Windows 删除共享限制那样禁止目录改名。临时写入/提交/清理均相对于该句柄，提交前重新检查原路径身份；观察到替换即拒绝发布最终名称。该范围不提供目录树原子快照，也不承诺对同一账户任意修改暂存目录的完整隔离。macOS 标准 /var、/tmp、/etc 根别名仅在 root 所有且解析为相同 /private 目录时展开，其他链接继续拒绝；此分支尚无 macOS 运行证据。

Linux 在独立 8 MiB tmpfs 验证真实 ENOSPC，返回磁盘错误并清理临时文件、保留同名原文件，释放空间后可再接收。容量预检、单文件格式限制、所有数据库/日志的总预算及 Windows/macOS 磁盘满仍为后续范围。

## 当前上限与线程归属

每片数据 256 KiB，socket 读缓冲 512 KiB；文本最多 8 MiB，路径最多 4096 UTF-8 字节，接收批次最多 1000 万项。文件清单/接收映射/接收明细各使用 2 MiB SQLite 缓存和 256 MiB 数据库上限；这是单库限制，**尚不是总磁盘预算**。清单每 512 项、接收映射每 256 项提交，接收明细每 256 项或 200ms 提交。模型/明细每页 100 项，发现最多 256 台，每台最多 16 个地址。

接收明细准入以同数据库跨进程锁串行化，清理过期完成/失败记录后，累计任务达到 1 万时拒绝新增。未核对的中断未知记录不被自动遗忘；查询每次最多核对 100 个失去所有权的接收记录，不加载全部任务。查询命令退出 0 表示查询成功，任务是否成功必须读取 `state`；`interrupted` 不能按成功处理。

工作线程内部创建、访问和销毁 socket、文件、清单与接收明细连接；GUI 主线程只处理受限频率的进度和有界结果。旧协议监听器只有一个活动接收任务，忙时显式断开新连接。新版全局授信、公平排队和多通道尚待实现。

头像为 GUI 独立模块：最多四个请求、单次正文 128 KiB、输入尺寸 1024×1024、输出至多 64×64 / 32 KiB PNG，三秒总期限；服务端最多八连接、2 KiB 请求和两秒期限。只向发现的数字地址、传输端口加一及固定路径 `/dukto/avatar` 请求；不使用代理、cookie、认证复用或重定向。QML 只接收重新编码后的本地数据 URL。

## CLI 与完成语义

当前真实公开命令：`discover`、`send`、`send-text`、`receive`、`receipts show`、`config show/set`、`doctor`、`help`。所有服务器/多线程/恢复命令仍为后续范围，不提供返回固定成功值的入口。

JSONL 的 `eventVersion` 为 1，计数/字节/耗时/序号等 64 位量使用十进制字符串。进度 `stage` 区分 `scan/send/receive`，可附 `object`、`bytes/total`、`elapsedMs`。发送成功仅指本地输出结束，明确 `receiverVerified:false`；R6 不插入不兼容确认帧。接收结果包含本地任务 ID 和明细位置，可分页查询真实落盘名称和 SHA-256。

| 退出码 | 含义 |
| --- | --- |
| 0 | 对应操作成功；旧版发送仍不含远端确认 |
| 1 | 运行时错误 |
| 2 | 参数、配置、协议结构或输入边界错误 |
| 3 | 网络/无进展超时 |
| 4 | 权限或路径边界拒绝 |
| 5 | 磁盘/文件/数据库错误 |
| 6 | 完整性或源内容变化 |
| 7 | 用户取消 |

标准输入以 UTF-8 处理，空文本允许，超限/非法 UTF-8 明确失败。保持打开但不产出内容的管道按 `--timeout` 退出；取消读取与传输都使用同一退出码。非交互模式不等待终端键盘输入。Windows/Linux 管道超时与 EOF 已实测，Linux SIGINT 取消标准输入，以及 SIGTERM 停止空闲监听/SIGINT 停止部分接收通过；JSON 输出取消请求，退出前监听器析构等待工作线程清理，临时文件清除且后续可重新接收。Windows 隐藏独立测试控制台的真实 CTRL_C_EVENT 已验证空闲/活动接收及标准输入取消；物理按键与完整终端矩阵、macOS 仍待验证。

还未关闭的接口门槛包括：新版主/次版本、帧结构/能力协商、稳定身份、认证授权、任务幂等键、全局预算、检查点与完成确认顺序。因此 T06 继续进行，不能仅凭当前错误码表标为全部完成。

Windows Qt5 的 isSymLink 不覆盖 junction，源扫描现使用原生重解析点属性，并核对显式源的父目录链；三种 junction 源样本均在联网前拒绝。读取期间最后一个分量的替换仍需原生安全打开加固，不把静态拒绝测试作为完整竞争封闭的证据。
