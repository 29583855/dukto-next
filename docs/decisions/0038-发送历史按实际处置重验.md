# 发送历史按实际处置重验

日期：2026-11-06。

## 行为

历史完成核验先读取完整的原处置日志，要求其清单摘要、条目总数和字节总数与冻结清单一致。逐项处理只保留当前记录；已复制目录固定当前原生目录对象，已复制普通文件固定源句柄，按 256 KiB 片段重新计算全文件 SHA-256。源缺失、大小或内容变化、授权映射不同均拒绝。空文件仍必须实际打开并核对摘要。

已跳过项只证明原持久决定，不解析当前源路径，不打开源，不要求当前源存在。继承跳过必须由原处置日志的目录根和父项关系支持；不能由“源现在不存在”反推跳过。全跳过的原目录删除后，可以核验原完成决定，不会重新扫描或发送该目录。

服务端下载完成历史和客户端上传回执恢复共用 `verifyCompletedSource()`。客户端缺失上传回执时，分页接收证据可恢复 copied/skipped，核对实际确认字节和跳过根后仍须通过完整日志、复制源重验、双方摘要及必需计量。它不能依据最终成功状态补造本轮传输进度。

服务端上传完成历史使用显式处置回调核对所有条目的路径、copied/skipped 和跳过根；只核对 copied 回调不足以证明混合历史。服务器共享根及当前授权仍须有效，跳过不授予额外访问权。新下载任务扫描前仍解析并检查当前授权源，历史免读规则仅用于原跳过项。

## 验证与边界

专项使用真实复制文件、空文件、目录和跨三页的 206 项全跳过日志；验证同大小正文篡改、删除复制源、目录改成文件、错误源映射、不同清单、不完整处置、分片读取中取消，以及跳过路径后来变成文件。核验前后比较原清单/处置库的实际字节摘要和 SQLite 连接回收。

实际构建、核心与正式 CLI 协议结果由本轮回执记录，未通过前不授予资格。此项补齐历史核验基础，不等于公开 skip 已开放。上传入口在历史核验前仍有源扫描等后续接线；能力协商、GUI/CLI 策略、公开跳过全流程和故障/资源验收继续，`deliveryComplete=false`。
