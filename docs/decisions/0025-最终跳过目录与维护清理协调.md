# 最终跳过目录与维护清理协调

日期：2026-11-07；实现批次：R111。

目录接收在发布前遇到外部同名目录时，`skip` 会先持久保存 `skip_final` 决定，再删除自有临时目录，最后确认 `cleaned=1`。此前本机过期维护直接保留全部 skip 目录。R111 让已有客户端和服务器 `cleanup preview|run` 接续这一处置，无需新增命令参数。

处理前同时校验冻结强清单、原接收准备、最终 skip 决定、目录预约、随机临时名、原生身份及原父目录。没有对应最终决定的 skip 项继续保留；已有目录删除意图但对应决定丢失时拒绝操作。确认标志必须为 SQLite 64 位整数 0 或 1。

只有原生身份匹配的空临时目录可以删除，非空目录不会递归清理。维护器先 FULL 提交目录删除意图，删除后在同一个 FULL 事务中更新 `directory_cleanup.cleaned` 和 `skip_final.cleaned`；任何一个确认失败，两个更新一起回滚。原目录预约和最终 skip 决定保留，使客户端重启后继续得到同一个跳过结果。

| 中断时点 | 维护或恢复行为 |
| --- | --- |
| 最终 skip 决定尚未持久化 | 不根据当前同名目标推断新决定，维护保留临时目录 |
| 决定已持久化，临时目录仍在 | 核验临时目录身份后保存删除意图，只删除该空临时目录 |
| 接收器已删除临时目录，尚未确认 | 没有维护意图时必须另核对原冲突目标身份，再补建意图并原子确认 |
| 维护器已删除临时目录，尚未确认 | 依赖原持久删除意图重入，原子补确认两个完成位 |
| 第二个确认写入失败 | 事务整体回滚，两个完成位保持 0，后续可重入 |
| 两个确认均已提交 | 返回幂等结果，不删除后来出现的同名新目录 |

客户端与服务器各有真实冲突、只读预览、上述两种删除后中断、第二个更新失败回滚、重复执行测试。R111 四原生平台各26个CTest和目录专项49条通过；Windows UCRT/MSVC各四项相关CTest另有本机原件。双Mac各一条已有Darwin端口独占XFAIL继续保留，完整协议和正式发布资格另验。

此项不回收没有原生身份的创建中对象，不删除最终目录/文件、强清单或任务历史，也不承担自动GC或全局磁盘预算。维护锁约束同软件使用者；POSIX原生API不能提供对任意外部改名的文件系统CAS。

本轮仅验收由维护器重复进入的恢复顺序。客户端若在维护中断后先运行原接收器，再进入维护，其最终skip清理位与旧维护意图的收敛仍待专项；当前遇两个完成位不一致会停止并报告完整性错误。全部处置协调不能由本轮专项代替。
