# 跨进程磁盘预算接入设计

更新日期：2026-11-08。状态：待实现。以R119固定SQLite/VFS为接口基础；本文件只细化Q01–Q05，不授予总配额资格。

同一状态目录的GUI、CLI和服务必须共享预算。各进程的BufferCredit只管理本进程应用缓冲，PrivateStore共享使用锁允许多个正常使用者，不能充当预算账本。额度必须在实际写入前申请，失败后的文件可能部分增长，不能仅按返回码退款。

| 写入入口 | 当前实际位置与用途 | 后续接入要求 |
| --- | --- | --- |
| PrivateStore::write | service/clients/transfers中的身份、配置、恢复凭据及创建空库 | 原子替换期间同时计量旧对象与新临时对象；同步/替换/对账失败均保持保守占用 |
| TaskStore、StrongManifest、DurableReceive、DispositionJournal | service/transfers中的任务、强清单、接收与最终处置 | 主库、journal、WAL、shm按原生身份和类别协调；不删除有效幂等记录 |
| UploadManifest、维护器、逐项查询 | 源扫描、恢复/清理、只读快照 | 只读查询也可能触发热日志恢复或临时排序，不能一律分配零额度 |
| Manifest、旧版接收roots.sqlite | 系统临时目录中的原版发送清单/接收映射 | 原生VFS临时对象纳入同一预算主体，不能因不在状态根而遗漏 |
| Catalog、GUI history.sqlite | 状态父目录中的receipts.sqlite和历史 | 历史/缓存合计256MiB；GUI裁剪历史不得提前删除有效请求身份 |
| BrowseStore | service中的目录快照正文和说明 | 同时覆盖IncomingFile临时写入与最终快照，不只计量JSON说明 |
| IncomingFile、DurableReceive正文 | 用户目标父目录中的临时正文、覆盖旧文件及最终提交 | 临时正文独立预算和合计；最终用户文件不进入自动GC，跨卷分别核对空间 |
| 诊断导出、截图/渲染报告 | 用户指定输出及临时目录 | 输出本身有界；不可把输出目录当作可自动删除的状态根 |

账本自身使用有上限的固定结构和持久化协议，不使用会再递归申请额度的SQLite连接。固定槽保存活动授信和身份，聚合值采用校验过的64位整数；槽耗尽受控拒绝，禁止按无限文件数扩张内存映射。最终槽数、双份记录大小及账本预留额度在实现时写入格式契约并实测，不能先宣称任意并发可用。

建议按以下顺序接入：

1. 先补齐SQLite原生文件身份/真实长度及共享内存实际分配范围查询。VFS临时文件可能没有路径，连接内序号不是跨进程文件身份；不能使用Qt/SQLite私有结构偏移猜测系统句柄。Windows与POSIX须有分别验证的适配。
2. 定义受保护状态父目录的预算域，记录各状态根的原生身份、卷和类别。路径别名不能生成两份独立预算；不同卷不能共用一份可用空间数。未知项保守计量并保留。
3. 在原生预算锁内持久化预留，释放预算锁后执行单次原生I/O，再短暂加锁记录完成。预算锁内不等待网络、扫描全目录、SQLite锁或用户输入；不能持有它调用会递归申请额度的写入接口。
4. 同一文件多连接按真实身份协调；替换产生新身份，旧占用只有在真实对象释放后才能归还。部分写入、截断失败、预分配及WAL/shm必须按实际结果重新核对，无法核实时保留预留。
5. 直接退出留下的授信进入待核对状态。PID不存在不等于对应文件消失；只在取得足够的原生生命周期/对象证据后恢复额度。与其他活动进程不能安全协调时停止新准入，提供明确诊断。
6. 预算不足返回稳定可操作错误，保留当前原文件、检查点及请求身份。释放其他任务额度后允许继续同一恢复流程，禁止自动删除有效幂等记录来腾空间。

锁顺序必须在代码实施前形成表格，覆盖状态共享/维护锁、任务/目标预约锁、SQLite内部锁及预算锁。现有维护器只有取得独占维护资格才删除自有过期项，预算不足不能绕过该条件。账本损坏、版本不兼容或身份不符时默认拒绝新增长，不将未知记录重置为零。

验收依次包括：两个真实进程争夺最后额度；同文件多连接及两个任务混合；SQLite主库/journal/WAL/shm/排序临时项分别拒绝；原子替换前后退出；部分I/O失败后的真实占用；暂停/取消/恢复及重启不重复归还；大量文件多轮后账本、内存、句柄和线程保持有界。Windows、Linux及双Mac按相同固定格式实际验证。

实现进度继续以[磁盘总配额实施清单](磁盘总配额实施清单.md)为准。R119生产默认策略只转发，quotaEnforced=false。
