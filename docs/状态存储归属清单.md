# 状态存储位置与归属接入清单

更新日期：2026-11-08。状态：已完成现有代码入口核对；运行时全根登记、持久归属和总预算仍待实现。本文件是Q01/Q02的接入依据，不能作为配额或自动回收完成证据。

“状态父目录”取当前GUI的数据目录或CLI显式的`--state-directory`，不能写死为默认用户目录。GUI和CLI指向同一个父目录时须进入同一预算域。根的路径只用于定位，原生根身份、卷和登记生命周期共同约束归属；路径字符串相同、UUID相同或后缀相同均不够。

## 登记与重新核对约束

每个写入入口需要显式携带预算域、类别、业务关联以及操作生命周期。业务关联允许域级配置、本地请求和已知任务三个实际场景；无关联不能偷偷使用零额度。登记使用固定槽，名称和诊断字段有上限，槽耗尽或路径超限受控拒绝，禁止累积所有对象名称的内存表。

根登记应先固定实际目录并核对私有权限及共享使用资格，再登记原生根身份和卷。不同路径指向同一个对象不能创建可重复使用的两份额度；不同卷分别观察可用空间，域总额与卷准入均须满足。根被替换或锁对象换代时停止增长，不将新路径自动视为旧域延续。

同一共享库可以关联多个任务，合计计量按真实对象进行。原生身份还可能在对象释放后被系统复用，所以“平台、卷、ID相同”只是当前观察，必须结合本应用的持久登记修订、活动授信和对象生命周期。旧记录与新对象无法区分时保留旧占用并拒绝新的增长，不能仅按PID或文件名判定它们相同。

私有根维护枚举只提供实际存在对象的观察。分类器须对照经现有校验器确认的持久绑定和任务记录；名称只用于查找候选。不存在绑定、版本未知、记录损坏、无法完整观察或未登记的对象计入未知类别并保留，不进入自动删除队列。对外查询继续限制页数和序列化长度，不暴露私有正文、令牌或内部逐项身份。

只有取得全部相关根的适当资格并覆盖登记中的临时位置，才能报告“域总量”。任一活动进程或未知根使观察不完整时应明确报告范围，不能将已成功扫描的子集当作完整统计。SQLite匿名对象和退出后遗留的未决授信必须通过后续持久账本恢复协议纳入，R121单根观察不提供这一保证。
