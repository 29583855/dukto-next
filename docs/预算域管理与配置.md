# 预算域管理与配置

更新日期：2026-11-08。R125 提供三平台相同的独立 CLI 管理入口，以及持久额度配置和中断恢复。当前仅管理账本已登记对象；生产写入的总预算限制、历史迁移、物理分配准入和自动回收仍在实施。

先指定状态父目录，再在其私有 `budget/` 子目录建立协调域。普通父目录不会被改成私有根，已有 `history.sqlite`、`receipts.sqlite` 和用户文件不会自动移动或删除。GUI 当前仍在旧位置使用历史，不能把创建 `history/` 标记当作历史迁移已完成。

```text
dukto-cli state budget init --state-directory <目录> --budget-total 21474836480 --budget-history 268435456 --budget-metadata 1073741824 --budget-body 17179869184 --budget-unknown 268435456 --json
dukto-cli state budget show --state-directory <目录> --json
dukto-cli state root bind --state-directory <目录> --state-root transfers --json
dukto-cli state root show --state-directory <目录> --state-root transfers --json
```

五个额度均以规范非负 64 位十进制字节数显式提供，没有隐含“无限”或业务默认值。总预算与类别预算同时约束账本准入；类别额度可以大于总预算，并不将类别最大值预扣为实际占用。历史额度不得超过既定 256 MiB。总额和元数据额至少容纳固定账本及协调标记，实际成员标记也在创建前计量。

查询返回 `revision`，修改时携带这个修订，并重新提供完整的五项额度：

```text
dukto-cli state budget set --state-directory <目录> --budget-revision <查询所得修订> --budget-total 42949672960 --budget-history 268435456 --budget-metadata 1073741824 --budget-body 34359738368 --budget-unknown 268435456 --json
```

修改需要协调根独占维护。根被其他本应用使用者占用时立即失败，不等待用户关闭程序，也不将共享锁原地升级。旧修订被拒绝，调用者先重新查询再决定新配置。相同修订和相同配置不写盘；成功修改递增修订，不改变域、成员代数、对象槽、占用或未决保留。新额度低于已有占用与保留额时拒绝并保留原配置；已有实际透支只能通过足够的新额度解除，不能通过重置占用清零。

根管理只接受 `service`、`clients`、`transfers`、`history` 四个固定子目录。首次绑定需要该根独占维护；重复绑定核对旧标记而不重复计费。查询只打开已有目录和标记。非法、重复、溢出选项在创建目录前拒绝，不允许将任意用户目录认领为可回收状态根。

JSON 与人类输出均报告总额、四类额度、已记账占用及保留额；数字为十进制字符串，修订不会经浮点数截断。输出 `scope=registered-ledger-objects` 和 `productionQuotaEnforced=false` 明确范围。该查询没有扫描未知文件，因此不是整个磁盘或全部状态的完整实际占用报告。普通传输命令拒绝误传预算选项。

持久格式沿用 `DKBUDG01` 固定账本和原对象槽事务；新配置事务使用 `DKBUDCF1` 的 4096 字节写前意图，包含旧／新完整头及修订，后半保留区必须为零。意图同步、写头同步、清意图同步分别执行。重开向前重放完整意图，保持对象槽不变；未知、撕裂、过期意图或夹带其他头变更均拒绝。旧版遇到尚未清零的新配置意图会拒绝打开，不会把它当作空日志。

目前 CLI 与核心均保留失败原件，不自动修复损坏账本，不按 PID 退款，不迁移未知控制文件。生产全根注册、普通历史安全迁移、SQLite／原子替换／正文写前授信和物理分配对账、有效幂等保留及自动 GC 继续按[实施清单](磁盘总配额实施清单.md)推进。
