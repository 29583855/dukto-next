## 已发现并修复的问题

1. Windows 下 QTemporaryFile 的关闭不一定释放原生文件句柄。测试发现静态重命名失败，已改用临时文件对象自身重命名并转移所有权；同名保护及清理测试通过。
2. 没有可见控制台时，Qt 的内置帮助/版本输出可能弹出对话框并阻塞。CLI 已改为直接输出到标准输出，实际帮助和版本命令可退出。
3. 已修正发送清单中来自不同父目录的同名根目录映射：独立分配顶层别名，避免接收后合并目录；回归通过。
4. 发现列表改为按 R6 完整签名及端口聚合多网卡地址，每设备最多 16 个地址并分别过期；真实 UDP 双地址/退出回归通过。R6 没有稳定 UUID，同签名同端口的设备仍有歧义，新版协议需提供身份。
5. 原版文本互传发现发送哨兵后的 NUL 少一个字节，原版曾报接收错误；已改为按实际字符串长度追加 NUL，独立文本线格式、空文本与双向原版核对通过。
6. 接收目录切换改为在空闲监听器中更新，保持端口绑定；不再删除并重建监听器。GUI 所有发送入口在端口窄化之前统一解析/验证 IPv4、主机名及 IPv6 格式。
7. 接收文本历史存入有磁盘上限的数据库、按记录读取；复制支持选区，剪贴板空值禁用，截图准备阶段占用任务槽位。批次明细分页已实现，三平台截图行为仍未验收。
8. 批次内重复、大小写或 Unicode 规范化冲突路径明确拒绝；已提交文件保留在接收明细，后续文件失败不能误报整个批次成功。
9. 单实例增加文件锁，避免同时启动时删除另一进程的有效本地监听通道；Windows 冷/热并发启动已通过。
10. GUI 首次弹窗原来在组件加载阶段打开而不可见，改为进入事件循环后显示；首次接受/重启真实验证通过。测试配置显式使用 INI 格式，防止独立测试目录被 NativeFormat 绕过。
