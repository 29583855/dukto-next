# 过期任务临时文件清理

更新日期：2026-11-07。

R108增加本机服务器上传任务的清理入口。它回收接收日志中已经记录原生文件身份的未完成临时正文；任务、原请求ID、强清单、逐项处置和接收日志继续保留。客户端重复使用原请求ID仍得到原来的终止任务，不会因清理而创建第二份传输。

先停止使用这个服务器状态目录的GUI、CLI和服务进程，再执行本机维护。普通使用者持有共享锁，清理持有独占锁；有占用时立即拒绝，不等待或抢占活动任务。旧版程序、外部数据库编辑器和跨机器网络目录不在此锁的保护范围。

```text
dukto-cli serve cleanup preview --state-directory <状态父目录> --client <客户端UUID> --task <任务UUID> --json
dukto-cli serve cleanup preview --state-directory <状态父目录> --client <客户端UUID> --task <任务UUID> --after <上一页after> --json
dukto-cli serve cleanup run --state-directory <状态父目录> --client <客户端UUID> --task <任务UUID> --json
```

这里使用`<状态父目录>/service`中的服务器记录，不需要远端IP或网络连接。必须明确指定一个客户端和一个任务，不能传入任意文件路径。`preview`每页最多100个接收文件条目，`more`及`after`供继续翻页；`run`处理整个指定任务，不接受分页参数，不把全部条目积累在内存中。`--json`提供条目行动、是否过期和已清理文件数；标准输出按UTF-8 JSONL编码。

暂停或中断任务默认保留7天；失败或取消任务保留30天。时间按任务数据库中的UTC更新时间计算。未到期、活动、完成或提交中的任务不允许执行清理。预览不会终止任务或删除正文；第一次打开旧任务库可能执行正常架构升级。

执行先在FULL同步事务中持久保存过期凭据，再将暂停/中断任务置为失败，随后逐文件FULL提交删除意图。只有随机`.dukto-UUID.part`名称、冻结清单条目、映射父目录、接收根原生身份和临时文件原生身份全部匹配时才删除。删除后再次FULL确认；进程在删除与确认之间退出，可以用同一命令续做。已经确认删除后出现的同名新文件会保留。

用户源文件、已发布最终文件、目录、没有已记录身份的创建中临时项均保留。文件或目录存在提交结果不确定的记录时，预览和执行都会拒绝，必须先按原任务恢复并核验结果；不能将其推定为垃圾。身份被替换、数据库损坏、锁冲突或删除失败均明确报错，现有证据保留。

SQLite旁路文件先验证私有权限和大小，接收库及其旁路合计受单库预算约束。支持由SQLite自己恢复DELETE模式回滚日志；不直接删除`-journal`、`-wal`或`-shm`，遇WAL模式接收库拒绝维护。任务库升级至版本三，版本一/二记录及幂等参数保持；旧版本程序不支持降级打开新任务库。

## 客户端未完成下载正文清理（R109）

R109增加客户端本机维护入口。先退出使用同一客户端状态目录的 GUI、CLI 和后台服务，再预览或执行。维护模式取得状态目录独占锁，并要求任务接收日志没有活动接收者；冲突时立即拒绝。命令作用于`<状态父目录>/transfers`，默认状态父目录为 Qt 的`AppLocalDataLocation`。

```text
dukto-cli client cleanup preview --state-directory <客户端状态父目录> --task <任务UUID> --json
dukto-cli client cleanup preview --state-directory <客户端状态父目录> --task <任务UUID> --after <上一页after> --json
dukto-cli client cleanup run --state-directory <客户端状态父目录> --task <任务UUID> --json
```

`preview`每页最多列出100个文件；`run`逐条删除已记录原生身份、且任务绑定和强清单均匹配的未完成下载临时正文，随后清除该文件的块检查点并将文件恢复为`planned`，同一任务可从头重新下载。操作不连接服务器、不变更任务ID或请求幂等记录。重复运行可处理进程在删除正文后、SQLite事务提交前退出的情况；SQLite使用FULL同步。

已完成文件、目录项、跳过策略下的文件、任务历史及清单均保留，不释放任务数量上限。状态或文件身份不匹配、数据库证据无效、活动锁、SQLite旁路预算超限或其他删除错误会停止并报告错误。该入口不清理通用缓存、目录临时项或全局过期任务，也不实现总磁盘预算；这些仍是独立工作。

这两种清理入口尚不承担全局自动回收、目录临时项回收、元数据删除或总磁盘配额。历史256MiB、活动清单总预算及SQLite所有旁路的全局计量仍是计划中的独立验收项。保留元数据意味着任务数量上限不会通过本命令释放。

服务器端实现见[过期清理核心](../src/core/expiredtaskcleanup.cpp)、[任务过期事务](../src/core/taskstore.cpp)及[原生测试](../tests/expired_task_cleanup_tests.cpp)；客户端实现见[下载清理核心](../src/core/clientdownloadcleanup.cpp)及[客户端清理测试](../tests/client_download_cleanup_tests.cpp)。完整交付状态以[计划](../开发计划与进度.md)为准。
