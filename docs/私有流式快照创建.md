# 私有流式快照创建

更新日期：2026-11-09。R148正在验收。

GitHub Windows R147完整核心的浏览和ServerPanel真实目录列表失败。原件显示私有正文所有者校验拒绝；Qt临时文件在提升账户下可能采用Administrators默认所有者，继承私有DACL不足以保证当前用户所有权。普通接收文件继续保留原有策略，私有快照改由PrivateStore::create创建。

创建临时文件时就提供当前用户所有者及私有DACL；POSIX继续固定父目录、0600和O_NOFOLLOW。顺序流在每次写入之前检查本次上限，不拼接完整快照；回调即使忽略超限/短写，发布前也会拒绝。回调取消/抛错、同步失败或目标竞争保持原件，未提交临时文件尽力按固定根清理；已发布而目录同步失败的对象保留，不宣称提交成功。

发布只允许新键，不自动更名或覆盖；正常路径先重验私有权限、文件同步，再独占原子发布。浏览继续持有browse.lock、数据句柄授信、逐项扫描/取消/源目录稳定核对、现有字节和快照数量上限。发布后才记录R147换代凭据。

本次上限只控制该次流写入，不代表跨进程磁盘总配额、历史预算或崩溃后全局对账完成。Windows提升账户的修复资格须由新的真实原生CI结果授予；本机标准用户通过不代替它。
